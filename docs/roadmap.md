# Proposed research-grade milestones

1. **Optional exact polytope pipelines beyond cddlib:** reverse search, symmetry generator actions and low-memory streaming facets.
2. **Algebraic scenario specifications:** parameterized rational equivalences, named preparations, setting aliases, and effect coarse-graining maps.
3. **Quantum optimization:** fixed-dimensional see-saw for arbitrary POVMs and equality-linked preparations/measurements, including tested primal/dual SDP residuals.
4. **Prepare-and-measure SDP hierarchy:** dimension-independent quantum upper bounds with the correct state/measurement moment algebra and operational equivalences. Do not substitute a Bell NPA hierarchy.
5. **Statistical modules:** confidence regions, robust operational equivalences, and noise robustness under explicitly specified models.
6. **Developer experience:** documented benchmarks for large cases, bindings to GAP for symmetries, CI exercising GMP cddlib where supported, PyPI release and docs website.

These are planned extensions and are not represented as implemented in v0.2.0.
