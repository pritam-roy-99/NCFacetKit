# NCFacetKit v0.4.0

Exact feasible-basis pivot traversal replaces the combinatorial candidate-basis scanner. Use `Scenario(..., vertex_backend='pivot')` for exact rational component vertices. Use `vertex_backend='cdd'` and `facets(backend='cdd')` for optional GMP-backed complete facet computation. The pivot budget counts visited feasible bases, including degenerate exchanges. Qhull candidate facets are checked exactly but completeness is not certified.

The 24-variable sparse benchmark has 134,596 combinatorial candidate bases and 19 preparation vertices; pivot enumeration took approximately 0.3 seconds in the development environment. Run `python benchmarks/run.py --pivot`.

Thirty regression tests passed in GitHub Actions. One optional GMP-backend comparison is skipped when pycddlib is unavailable.
